# Snake on Zybo FPGA

**VHDL · Vivado · VGA**

[English](#english) · [Español](#español)

## English

A hardware implementation of Snake on the Zybo FPGA. Game logic and VGA video output are implemented in the Vivado project.

### Architecture

`Game logic → VGA output`
